# VozSalud

VozSalud es una aplicación web académica enfocada en el cuidado y bienestar de la voz desde el área de Fonoaudiología.

## Tecnologías

- HTML
- CSS
- JavaScript
- Tailwind CSS mediante CDN
- Lucide Icons
- LocalStorage

## Estructura

- index.html: calendario principal.
- habitos.html: hábitos saludables.
- informacion.html: información sobre higiene vocal.
- css/styles.css: estilos personalizados.
- js/app.js: funciones generales.
- js/calendario.js: lógica del calendario.
- js/habitos.js: información de los hábitos.
- js/idiomas.js: traducciones.
